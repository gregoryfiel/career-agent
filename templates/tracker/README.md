# Tracker template

Copy `applications.csv` to the repository root (or wherever you keep your working data — remember
`applications/` is gitignored) and let skill `04` maintain it.

**Status values:** `draft` · `sent` · `incomplete` ⚠️ · `screening` · `interview` · `test` ·
`offer` · `rejected` · `withdrawn` · `stale`

`incomplete` is the one to watch. A half-finished application on a profile-based ATS is a started
record sitting in the employer's system that usually expires silently.
